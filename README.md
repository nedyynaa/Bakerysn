# 🥐 Bakerysn - Web Toko Roti

Aplikasi web sederhana untuk menampilkan katalog produk toko roti berbasis **Next.js** dan **Express.js**.

---

## 📝 Latar Belakang

Proyek ini dibuat untuk digitalisasi katalog produk toko roti secara sederhana. Aplikasi ini menghubungkan tampilan antarmuka *frontend* ke *backend* guna menampilkan daftar produk roti secara *real-time*.

---

## ⚡ Fitur Utama

- **Landing Page UI**: Tampilan beranda modern mencakup Navbar, Hero Section, Banner Promo, dan Footer.
- **Katalog Produk**: Menampilkan daftar roti beserta harga.
- **Integrasi Fetch API**: Pengambilan data produk dari server backend Express.js ke frontend Next.js.

---

## 🛠️ Teknologi

- **Frontend**: Next.js, Tailwind CSS
- **Backend**: Express.js, Node.js
- **Version Control**: Git & GitHub
